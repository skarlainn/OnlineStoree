# OnlineStore

## Описание

Онлайн-магазин

Интернет-магазин


## Содержание


* директория config
* директория catalog 
* директория blogs
* директория users

1. **catalog** содержит модули для функционирования приложения, шаблоны страниц, директорию с миграциями, директорию с кастомными командами
2. **config** с основными настройками проекта
3. **static** включает в себя папки со стилями и скриптами (CSS и JS)
4. **users** отвечает за логику работы с пользователем (регистрацию, авторизацию, настройку разрешений)
5. **screenshots** содержит скриншоты с вызовом команд из командной строки
6. **media** содержит медиафайлы (фото продуктов)


Приложение Catalog состоит из 4-х страниц:
1. contacts.html
2. home.html
3. product_details.html
4. products_list.html

Приложение Blog содержит 4 рабочих шаблона:
1. blog_list.html
2. blog_detail.html
3. blog_form.html
4. blog_confirm_delete.html

Запуск программы осуществляется через модуль manage.py
В приложении catalog присутствует кеширование деталей и списка продуктов при помощи Redis
